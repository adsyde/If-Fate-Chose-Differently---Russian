# История изменений

Версия перевода привязана к версии мода: она повторяет версию
If Fate Chose Differently, под которую собран перевод. Версия оригинала взята
из его `meta.lsx`.

## 1.0.0.9

Первый выпуск перевода под If Fate Chose Differently - Wyll Pact Points Overhaul 1.0.0.9.

- Переведены все 95 строк мода: реплики Уилла, варианты ответа игрока,
  реплики рассказчика в видении у Мизоры.
- Терминология сверена с официальной локализацией BG3 по файлам игры:
  «договор», «вассал Зариэль», «Клинок Фронтира», «Война крови»,
  «Побережье Мечей», «Врата Балдура», «дьяволица» о Мизоре.
- 15 реплик мода дословно повторяют строки игры — для них взят официальный
  перевод.
- Реплики игрока сформулированы так, чтобы не требовать грамматического рода.
  Род есть только у вариантов для конкретных происхождений.
- `contentuid` и `version` каждой строки сохранены без изменений.
