# If Fate Chose Differently - Russian

Русская локализация мода [If Fate Chose Differently - Wyll Pact Points Overhaul](https://www.nexusmods.com/baldursgate3)
для Baldur's Gate 3. Отдельный мод-патч: файлы оригинала не трогает, ставится рядом.

В менеджере модов отображается как **If Fate Chose Differently - Russian**.

| | |
|---|---|
| Версия оригинала | **1.0.0.9** |
| Строк в моде | 95 |
| Переведено | **95 (100%)** |

Мод переделывает историю договора Уилла с Мизорой: новые реплики в лагере,
в Колонии и в разговорах с Уиллом. Почти весь текст — озвученные диалоги.
Озвучка остаётся английской, переведены субтитры и варианты ответа.

## Установка

1. Скачайте архив из раздела [Releases](../../releases).
2. Распакуйте и положите `.pak` в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`
   — либо импортируйте архив целиком в BG3 Mod Manager.
3. Включите мод в менеджере модов **после** оригинального
   If Fate Chose Differently - Wyll Pact Points Overhaul.
4. Язык игры — русский.

Мод-перевод объявляет оригинал своей зависимостью, поэтому в списке загрузки
он встанет после него. Во встроенном менеджере игры он может показываться выше
— это сортировка для показа, а не порядок загрузки. Привязки к конкретной сборке
оригинала нет: обновление самого мода перевод не ломает, но новые строки в нём
до следующего обновления перевода останутся английскими.

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| `data/translations.jsonl` | сам перевод: оригинал, перевод, статус и история каждой строки |
| `data/source.en.jsonl` | снимок английского текста текущей версии оригинала |
| `data/batches/` | рабочие порции, на которые разбит перевод |
| `glossary/glossary.csv` | согласованная терминология |
| `glossary/style-guide.md` | правила оформления |
| `reports/` | отчёты о сверке с новой версией оригинала и о контроле качества |

Одна строка `data/translations.jsonl` выглядит так:

```json
{"contentuid": "h79c8d80fac71446f921649e1f5e06f62531a", "version": 2,
 "source": "Mizora? <i>You're</i> Zariel's asset?",
 "target": "Мизора? Так это <i>ты</i> — вассал Зариэль?",
 "status": "approved", "first_seen": "1.0.0.9", "last_seen": "1.0.0.9"}
```

### Статусы строк

| Статус | Значение | В сборке |
|---|---|---|
| `approved` | вычитан | **да** |
| `untranslated` | очередь ещё не дошла | нет |
| `needs_review` | английский текст изменился в новой версии оригинала | нет |
| `needs_context` | из текста не восстановить род говорящего или смысл | нет |
| `do_not_translate` | технический идентификатор или пустой оригинал | нет |
| `obsolete` | строки больше нет в оригинале, перевод сохранён на случай возврата | нет |

Перевод переживает обновления оригинала: при выходе новой версии строки
сверяются по `contentuid`, изменившиеся отправляются на вычитку с сохранением
прежнего варианта, исчезнувшие не удаляются.

## Принципы перевода

- Терминология сверена с официальной русской локализацией Baldur's Gate 3
  по файлам самой игры: *pact* — «договор», *Zariel's asset* — «вассал Зариэль»,
  *Blade of Frontiers* — «Клинок Фронтира», *Blood War* — «Война крови».
- 15 реплик мода дословно совпадают со строками игры — для них взят
  официальный перевод.
- Реплики игрока и обращения Уилла к игроку сформулированы без
  грамматического рода. Род есть только у вариантов, которые игра показывает
  конкретному происхождению: Карлах, Лаэзель, Шэдоухарт, Гейлу, Астариону.
- Игровая разметка (`<i>`, `<LSTag>`) сохраняется без изменений — это
  проверяется автоматически перед каждой сборкой.
- Идентификаторы строк (`contentuid`, `version`) никогда не меняются.

## Обратная связь

Нашли неточность в переводе — откройте
[issue](../../issues) и укажите `contentuid` строки или её английский текст.

Перевод распространяется отдельно от оригинального мода; все права на сам мод
и его содержимое принадлежат его автору (Magnetuning).
