# Style Guide для русской локализации If Fate Chose Differently

## 1. Обращение и грамматический род
- Уилл и игрок — спутники, обращение на «ты». Мизора с Уиллом — тоже на «ты».
- **Реплики игрока пишутся без грамматического рода.** Одна строка должна
  работать для персонажа любого пола: «Жду не дождусь этого дня», а не
  «Буду рад(а)».
- **Обращения к игроку тоже без рода:** «Твоя правда» вместо «Ты прав»,
  «В тебе столько доброты» вместо «Ты так добр».
- Исключение — варианты реплик, привязанные к происхождению. В диалоге они
  выбираются по тегу игрока `REALLY_<ИМЯ>`, поэтому род известен:

  | Тег | Происхождение | Род |
  |---|---|---|
  | `REALLY_KARLACH` | Карлах | женский |
  | `REALLY_LAEZEL` | Лаэзель | женский |
  | `REALLY_SHADOWHEART` | Шэдоухарт | женский |
  | `REALLY_GALE` | Гейл | мужской |
  | `REALLY_ASTARION` | Астарион | мужской |
  | `66c8b49a-…` | не найден в файлах игры | без рода |

- Действия игрока в курсиве — инфинитивом, как в игре: «<i>Промолчать — пусть
  Уилл решает сам.</i>» (ср. официальное «<i>Уйти.</i>»).
- Рассказчик (`*...*`) обращается к игроку на «ты», без рода: «*Ты видишь,
  как когтистая рука открывает капсулу...*».

## 2. Терминология
- Следовать терминам из `glossary/glossary.csv`.
- Если реплика мода дословно совпадает со строкой игры, брать официальный
  перевод и отмечать это в `notes`. Таких строк в моде 15.
- Отступать от официального перевода можно только по контексту и с
  пояснением в `notes`. Пример: в игре «Seven years.» — ответ на вопрос
  «когда» и переведено «Семь лет назад.»; в моде это начало раздумья Уилла,
  поэтому «Семь лет.»

## 3. Пунктуация и типографика
- Кавычки: «елочки» (« »).
- Тире: длинное тире (—) с пробелами. Оборванная реплика («my burden, but -»)
  заканчивается тире: «мое бремя, но —».
- Многоточие: три точки, как в ATE и в исходном тексте мода.

## 4. Буква «ё»
- В переводе используется «е» вместо «ё» — как в официальной русской локализации BG3.
- Исключение — случаи, где без «ё» меняется смысл.

## 5. Город в женском роде
- Уилл говорит о Вратах Балдура «she/her». По-русски название во
  множественном числе, поэтому в таких репликах — «город» и мужской род:
  «Я нужен городу», «Я не могу его бросить».

## 6. Имя «Зариэль»
- Через «э», **не склоняется**: «вассал Зариэль», «мчаться к Зариэль»,
  «издевательства Зариэль». Так в официальной локализации (405 из 406 строк).

## 7. Сверка терминов с игрой

Источник истины — локализация самой игры, а не память и не переводы
настольных правил. Проверять так: распаковать
`Data/Localization/Russian/Russian.pak` и `Data/Localization/English.pak`,
перевести оба `.loca` в XML и сопоставить строки по `contentuid`. Число строк,
где английский термин передан тем или иным русским, — достаточное основание.

| Оригинал | В BG3 | Подсчет |
|---|---|---|
| pact | договор | 231 строка; «сделка» 20, «пакт» 3 |
| Zariel's asset | вассал Зариэль | дословно, реплика Уилла |
| Zariel | Зариэль | 405 из 406 |
| Mizora | Мизора | 516 из 518 |
| Blade of Frontiers | Клинок Фронтира | 276 из 276 |
| Blood War | Война крови | 91 из 91 |
| Sword Coast | Побережье Мечей | 298 из 304 |
| Baldur's Gate | Врата Балдура | 1732 из 1777 |
| Waterdeep | Глубоководье | 282 из 284 |
| patron | покровитель | 200 из 233 |
| devil (о Мизоре) | дьяволица | «дьяволица» в 279 строках игры |
| parasite | паразит | 590 из 641 |

`scripts/qa.py` останавливает сборку, если в тексте появится «пакт»,
«Война Крови» с прописной или «Зариель» через «е» — вместе с запретами,
унаследованными от перевода Act Two Expansion.

### Известное предупреждение QA
`hada3fa9…` — дословная строка игры, где «No more pact» переведено «Никаких
больше обязательств». QA предупреждает, что нет слова «договор»; перевод
оставлен официальным.
