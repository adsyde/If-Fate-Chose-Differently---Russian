## 1. Роль и назначение
Этот репозиторий представляет собой проект локализации (патч-перевод на русский язык) мода **If Fate Chose Differently - Wyll Pact Points Overhaul** (автор Magnetuning) для Baldur's Gate 3.
Ты выступаешь в роли технического редактора, разработчика вспомогательных инструментов и оператора сборки.

Мод переделывает историю договора Уилла с Мизорой: новые реплики Уилла, игрока и рассказчика в лагере, в Колонии и в диалогах спутника. Почти весь текст — озвученные диалоги; озвучка остается английской, переводятся субтитры и варианты ответа.

Конвейер и правила перенесены из перевода Act Two Expansion (`../ATECCRus`) без изменений логики.

## 2. Архитектура данных и границы ответственности
- **`input/upstream/`** — строго READ-ONLY. Оригинальный `.pak` мода. В git не попадает.
- **`input/extracted/<версия>/`** — распаковка апстрима. Производная, в git не попадает.
- **`data/source.en.jsonl`** — снимок английских строк текущей версии мода. **Производный файл:** перезаписывается `extract_strings.py` при каждом обновлении апстрима, руками не редактируется.
- **`data/translations.jsonl`** — канонический источник данных (Single Source of Truth): переводы, статусы, история изменений оригинала. Переживает обновления мода, переводы из него не удаляются никогда.
- **`data/batches/*.jsonl`** — рабочие срезы для перевода. Вливаются обратно через `merge_batch.py`.
- **`build/`, `package/`, `releases/`** — производные артефакты сборки. В git не попадают.
- **`glossary/`** — терминологический словарь и правила стиля.
- **`config/tools.json`** — общий конфиг. **`config/tools.local.json`** — машинно-зависимые пути (Divine.exe), в git не попадает.
- **`reports/`** — отчеты синхронизации, QA и происхождения апстрима (SHA256 `.pak`).

Полное описание процесса — `docs/WORKFLOW.md`.

### Особенность этого мода
Английский текст оригинал держит в **корне** пакета: `Localization/English/MGNTN_WyllPactPoints.loca`, а не в папке мода. Фильтр распаковки в `config/tools.json` настроен под это. Под `Mods/MGNTN_WyllPactPoints/Localization/English/` лежат только лицевая анимация и звук — текста там нет.

## 3. Целостность XML и игровых идентификаторов
При генерации XML локализации и обработке строк соблюдай строгие правила:
1. **Атрибуты `contentuid` и `version` неизменяемы.** Никогда не генерируй новые UID и не удаляй существующие для оригинальных строк.
2. **Запрещено модифицировать или удалять переменные и плейсхолдеры:**
   - `{0}`, `{1}`, `{2}` и подобные числовые токены
   - `%s`, `%d`, `$NAME$`, `[1]`
   - Теги форматирования: `<br>`, `<font>`, `<b>`, `<i>`, `<LSTag ...>`
   - Любые внутренние GUID/UUID, упоминаемые в служебных текстах.
3. **Экранирование XML:** символы `&`, `<`, `>`, `"`, `'` должны быть экранированы согласно спецификации XML при экспорте.
4. **Кодировка:** строго UTF-8 (без BOM, если не указано иное).

## 4. Правила перевода
- Язык перевода — русский.
- Соблюдай официальную терминологию Baldur's Gate 3. **Она важнее переводов
  настольной редакции D&D 5e и важнее памяти: термины сверяются с файлами игры.**
  Способ сверки и таблица проверенных терминов — `glossary/style-guide.md` §7.
  - *pact* -> *договор* (не «пакт»)
  - *Zariel's asset* -> *вассал Зариэль*; *Зариэль* не склоняется
  - *Blade of Frontiers* -> *Клинок Фронтира*
  - *Blood War* -> *Война крови*
- Если строка мода дословно совпадает со строкой игры, бери официальный перевод
  и отмечай это в `notes`. Отступать от него — только по контексту, с пояснением.
- Соблюдай согласованность терминов по `glossary/glossary.csv`.
- **Грамматический род.** Реплики игрока и обращения Уилла к игроку
  формулируются без грамматического рода. Исключение — варианты реплик,
  привязанные к происхождению тегом `REALLY_<ИМЯ>`: у них род известен
  (Карлах, Лаэзель, Шэдоухарт — женский; Гейл, Астарион — мужской).
  Рассказчик (`*...*`) обращается к игроку на «ты», тоже без рода.
- Не переводи технические идентификаторы, имена скриптов, технические флаги, пути к ресурсам.
- Если контекст строки неоднозначен (неясен род персонажа, статус или отношение), выставляй строке статус `needs_context` и оставляй поле `target` пустым либо фиксируй комментарий в `notes`. Не додумывай смысл наугад.
- Контекст строки (кто говорит, что было перед ней) восстанавливается из
  диалогов мода: `Mods/MGNTN_WyllPactPoints/Story/DialogsBinary/**/*.lsf`,
  перевести в `.lsx` через Divine `convert-resource`.

## 5. Вызов инструментов и сборка
- Все вызовы **Divine CLI (LSLib)** производятся только через скрипты-обертки в `scripts/*.ps1`. Путь к Divine берется из `config/tools.local.json`; Divine требует абсолютных путей.
- Порядок работы при обновлении мода: `unpack.ps1` → `extract_strings.py` → `sync.py` → `make_batch.py` → перевод → `merge_batch.py` → `qa.py` → `build_mod.ps1`.
- Перед созданием любого пакета (`.pak`) обязательно выполняется `scripts/qa.py`. При блокирующих ошибках (потерянные переменные, измененные атрибуты `<LSTag>`, пустые обязательные строки) сборка немедленно прерывается. Флаг `-SkipQa` — только для отладки, публикация такой сборки запрещена.
- В `.pak` попадают только строки со статусом `approved`. Непереведенные строки отсутствуют в русском файле, и игра показывает для них английский текст оригинального мода.
- Локализация кладется в папку **самого мода-перевода** и только как `.xml`:
  `Mods/<папка мода-перевода>/Localization/Russian/<уникальное имя>.xml`, рядом
  `meta.lsx`. Раскладка выверена на живой игре в переводе Act Two Expansion,
  пять правил — в `docs/WORKFLOW.md`.
- Версия перевода повторяет версию мода: `IfFateChoseDifferently_Russian_v<версия>.zip`.
